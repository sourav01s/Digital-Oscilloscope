# STM32 Digital Oscilloscope

A simple digital oscilloscope developed using an **STM32L072CZ** microcontroller and ESP32
The project is designed to acquire an analog waveform using the STM32 ADC, process the sampled data, and display the waveform on an Webbrowser using ESP32.

Features

- Analog signal acquisition using STM32 ADC
- Real-time waveform display
- Adjustable sampling and waveform processing
- Estimate frequency measurement
- Voltage measurement
- Peak-to-peak voltage measurement
- Min/Max voltage measurement
- DMA-based ADC data acquisition

 Hardware Used

- STM32L072CZ
- ESP32 
- Analog signal input
- External signal generator for testing

 Software Used

- STM32CubeIDE
- Embedded C language
- Embedded c++ language
- STM32-LO72CZ Low-level peripheral configuration
- SPI
